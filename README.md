# RepUp 

**RepUp** is a native Android workout tracking application built using Java, Room Database, and MVVM architecture. It enables users to record workout routines, track sets/reps/weight, monitor volume, detect Personal Records (PRs), and view workout analytics over time.

## Tech Stack & Architecture
* **Language:** Java
* **UI:** XML, Material Design, RecyclerView, CardView
* **Database:** Room Persistence Library (SQLite)
* **Architecture:** MVVM (Model-View-ViewModel) + LiveData
* **Visualization:** MPAndroidChart
* **Authentication:** Firebase
